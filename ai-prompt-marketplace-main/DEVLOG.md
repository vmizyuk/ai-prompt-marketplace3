# Devlog — AI Prompt Marketplace

## Лабораторна робота №2: HTML-розмітка та семантика

- **Клонування та відкриття проєкту:** клонували репозиторій `vmizyuk/ai-prompt-marketplace` у домашню папку на macOS і відкрили його у VS Code.
- **Налаштування конфігів та середовища:** налаштували багатосторінкову збірку Vite з EJS (`index`, `catalog`, `prompt`, `cart`), адаптували запуск ESLint 9 через `ESLINT_USE_FLAT_CONFIG=false` та перевірили локальний прев'ю (`http://localhost:4173/`).
- **Перенесення файлів і розмітки:** додали дані проєкту (`src/data`), адаптивні зображення (`src/assets`), EJS-партіали (`src/partials`) та семантичну розмітку сторінок із мікророзміткою `schema.org`.
- **Історія комітів та пуш:** розбили зміни на серію окремих комітів і відправили їх у гілку `main` на GitHub.
- **Публікація на GitHub Pages:** задеплоїли збірку у гілку `gh-pages`, увімкнули GitHub Pages (`https://vmizyuk.github.io/ai-prompt-marketplace/`), перевірили сторінки та додали посилання на сайт у `README.md`.
